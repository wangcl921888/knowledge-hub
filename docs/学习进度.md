## 项目简介

**企业级 AI 知识库问答平台**（RAG 文档问答）—— 一个前端全栈学习项目。
用户上传文档，像聊天一样提问，AI 从文档中找答案并标注出处。

选定理由：AI/RAG 是 2026 大厂最稀缺、面试最加分的能力；业务本身是飞书/钉钉/Glean 等真实产品形态；技术覆盖最全（monorepo、微前端、SSR/RSC、PostgreSQL、全链路优化）。

## 技术选型

| 层 | 选型 |
|---|---|
| 主线框架 | React 19 + Next.js (App Router/RSC) + TypeScript 严格模式 + Tailwind CSS |
| 副线（管理后台） | Vue3 + Nuxt + Pinia（后期 Module Federation 微前端接入） |
| 数据库 | PostgreSQL + Drizzle ORM + pgvector（向量检索） |
| AI | Vercel AI SDK + RAG + MCP Agent + 流式(SSE) |
| 工程化 | pnpm + Turborepo monorepo、ESLint+Prettier、husky、Commitizen、GitHub Actions |
